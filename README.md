📚 Full Stack Open  (WORKSHOP) — Deep Dive into Modern Web Application Development<br>

This repository contains my completed workshop solutions for the Full Stack Open course, organized by the University of Helsinki..<br>
The course is one of the most comprehensive and respected resources for learning modern web development, covering both frontend and backend technologies.<br>

🚀 About the Course<br>

Full Stack Open focuses on modern JavaScript-based web application development.<br>
The main topics include:<br>
React<br>
Redux<br>
Node.js<br>
Express<br>
MongoDB<br>
GraphQL<br>
TypeScript<br>
Testing<br>
CI/CD<br>
Relational databases (PostgreSQL with Sequelize)<br>
Single-page applications<br>
REST API development<br>

The course emphasizes understanding how modern web apps are built from end to end — from the browser to the server and database.

🧩 Course Structure<br>
Part 0 – Fundamentals of Web Apps<br>
How the web works: requests, responses, DOM, callbacks, event handling.<br>

Part 1 – React Basics<br>
Components, props, state, event handlers, lists, forms.<br>

Part 2 – Communicating with the Server<br>
REST APIs, Axios, effect hooks, promises.<br>

Part 3 – Server-side Development with Node.js<br>
Express, routing, middleware, logging, deployment.<br>

Part 4 – Testing Express Servers & User Management<br>
Unit tests, integration tests, token-based auth.<br>

Part 5 – Testing React Applications<br>
React Testing Library, end-to-end testing.<br>

Part 6 – Advanced State Management<br>
Redux, reducers, actions, Redux Toolkit.<br>

Part 7 – React Router, Custom Hooks & Styling<br>
Routing, Webpack, UI libraries, hooks best practices.<br>


Part 13 – Relational Databases<br>
Using PostgreSQL with Sequelize ORM.<br>
Migrations, models, relations, and complex queries.<br>
